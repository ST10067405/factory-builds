## Where we already win

- We're the only one of the four with WhatsApp click-to-chat — all three competitors rely on their booking system or a contact form/phone number, with no WhatsApp CTA found on any of them.
- We're the only one with an embedded Google Map and directions link — all three competitors make a visitor leave the site (or dig for an address) to find them.
- We're the only one with any content/journal system — 6 articles plus FAQPage schema markup. None of the three competitors run a blog.
- We're the only one with an on-site chat widget — and ours routes straight into the real Rezerv booking link, not a dead end.
- We display the real, current Google rating (5.0★/20) directly on the page — none of the three competitors show a live review count on their homepage; Kloof and Westville show written testimonial quotes instead, which is a different (and slower-to-update) signal.

## Where competitors beat us today

- All three are live, indexed, real websites today. Ours is a draft (`noindex`), not yet public.
- InBalance publishes a full, real price list (R180 mat, R350 reformer) — ours still reads "R —" everywhere because we don't have confirmed class pricing yet.
- Kloof and Westville both carry written testimonial quotes from real clients; we only have the aggregate rating, not individual review text, to work with so far.
- InBalance and Imprint both run heavier, more feature-loaded Wix builds (online shop, gift cards, multi-channel social links) — more surface area, even if slower-loading than ours.

## What closes the gap

1. **A confirmed, real, priced class list** — copywriting (R850/page, or R3,500 for up to 5 pages) to turn "R —" into real numbers, closing the single biggest visible gap against InBalance specifically.
2. **Get the site live and indexed** — SEO Launch (R4,500 once-off) turns the current `noindex` draft into something Google can actually surface for "reformer pilates Gillitts" / "pilates Kloof" searches, where all three competitors already rank.
3. **Real client testimonial quotes**, once available — would close the gap to Kloof and Westville without needing to invent anything; worth revisiting once real Google review text can be sourced and verified.
4. **Newsletter setup (R2,800)** — none of the three competitors show an obvious retention/newsletter mechanism either; building this now would put GraySculpt ahead of the catchment, not just level with it.
