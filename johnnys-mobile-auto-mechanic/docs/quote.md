## 2. Recommended path — The Foundation (R16,500 once-off)

The Foundation covers this build exactly: a single-page site plus journal (≤5 pages), the motion already built in, WhatsApp wired up, Maps embedded, basic SEO, hosting + domain handled, 2 revisions.

**Why not more:** Johnny's doesn't take pre-planned bookings or run a menu/appointment system — the entire job is "answer the phone/WhatsApp before the next mobile mechanic in the search results does." That's a Foundation problem, not a Structure (R32,000) one. The Structure's booking form, gallery/testimonial depth and analytics stack are built for businesses with pre-plannable visits — Johnny's work is overwhelmingly reactive, same-day call-outs.
